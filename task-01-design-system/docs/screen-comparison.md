# Comparison: Screen Without and With the Design System

Evidence: `evidence/09-screen-without-system.png` (built without the system, `screen-without-system/index.html`) and `evidence/10-screen-with-system.png` (built with the system, `screen/index.html`).

When I compared both screens, I noticed that the screen without the design system uses a more basic visual style, with sharper card corners, grey borders and shadows, and a yellow information panel. The screen with the design system has more rounded cards, softer blue-tinted shadows, a consistent blue colour scheme and a light blue information panel. The typography and spacing also give the updated screen a more polished and consistent appearance. This shows how applying the design system helps create a more unified interface and makes the CarePoint brand more recognisable.
