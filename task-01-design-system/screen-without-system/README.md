# Screen without the design system

A contrast example for Task 1, Step 7. It is the same CarePoint home screen as `../screen/`, built the ordinary way: hardcoded colours, font sizes, shadows and font family, and no link to `tokens.css`.

It is only here to be screenshotted as `../evidence/09-screen-without-system.png`. Do not link it from the app.

Because it contains raw colour values on purpose, the raw-value search in `../evidence/07-raw-value-search.txt` was run before this folder existed. If the search is re-run now, hits in this folder are expected and are not a failure of the real screen.
